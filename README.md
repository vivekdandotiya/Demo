# NUMEN — Creative Direction & Strategy Studio

A high-performance luxury studio landing page built with React, TypeScript, Tailwind CSS, and GSAP.

## Features

- **The Live Studio Hero**: 3D tilted wall of floating app windows demonstrating an end-to-end creative pipeline (Design → Schedule → Publish → Measure) in pure DOM, SVG, and CSS with hardware acceleration.
- **True 4K Sharpness**: Vector precision, local tone-mapped photography, custom typography (`Instrument Serif`, `JetBrains Mono`), and zero canvas blur.
- **Dynamic Collaboration**: Simulated multiplayer teammate cursors with real-time feedback and visitor pointer interaction.
- **Responsive Architecture**: Fluid scaling from mobile (390px) to 4K displays (3840px) with custom breakpoint layouts and zero horizontal overflow.
- **Interactive Sections**: Filterable services index, interactive philosophy cards, audio feedback toggle, and custom cursor.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS**
- **GSAP** (GreenSock) + ScrollTrigger + MotionPathPlugin
- **Lucide React** (Vector icons)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
